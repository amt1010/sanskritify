## The five corrections

appearing exactly once in `ch01.txt`, are corrected in the authored JSON and
in this file. The raw extraction stays byte-identical — the fix lives here,
not there.

| Extracted (`ch01.txt`) | Corrected | Lint rule |
|---|---|---|
| `वर्मण ालां` | `वर्णमालां` | orphan-matra |
| `स्वतन्त्ररूपणे` | `स्वतन्त्ररूपेण` | none of the current rules — this is a syllable-order swap (`रूपेण` → `रूपणे`), not a joiner drop or an orphan matra, so it doesn't match any existing signature. Caught by reading line 11 directly. |
| `सामान्‍याः` | `सामान्याः` | zero-width-joiner |
| `सन्‍त‍ि` | `सन्ति` | zero-width-joiner |
| `वरण्मालायाम्` | `वर्णमालायाम्` | none of the current rules — the virama moves from र to ण with no space or joiner involved, so no whitespace-based signature catches it. Caught by reading line 18 directly. |

All five were re-checked directly against the committed `ch01.txt`: each

## ॠ dropped from the short/long concept

The plan's original concept text listed `आ ई ऊ ॠ` as the long vowels. `ॠ`
(U+0960) occurs 0 times in chapter 1's extraction, and 3 times in the whole
16-chapter corpus, all in chapter 5. "आ ई ऊ ॠ are long" is correct Sanskrit
grammar, but nothing in chapter 1's own text supports teaching ॠ here, so
`con.ch01.hrasva-dirgha` covers only अ इ उ / आ ई ऊ. The worksheet asks the
repo owner to confirm the chapter really omits it.
