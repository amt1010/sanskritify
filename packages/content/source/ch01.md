## The five corrections

`pdftotext` reorders conjuncts and drops joiners. These five words, each
appearing exactly once in `ch01.txt`, are corrected in the authored JSON and
in this file. The raw extraction stays byte-identical — the fix lives here,
not there.

| Extracted (`ch01.txt`) | Corrected | Lint rule |
|---|---|---|
| `वर्मण ालां` | `वर्णमालां` | orphan-matra |
| `स्वतन्त्ररूपणे` | `स्वतन्त्ररूपेण` | none of the current rules — this is a syllable-order swap (`रूपेण` → `रूपणे`), not a joiner drop or an orphan matra, so it doesn't match any existing signature. Caught by reading line 11 directly. |
| `सामान्‍याः` | `सामान्याः` | zero-width-joiner |
| `सन्‍त‍ि` | `सन्ति` | zero-width-joiner |
| `वरण्मालायाम्` | `वर्णमालायाम्` | none of the current rules — the virama moves from र to ण with no space or joiner involved, so no whitespace-based signature catches it. Caught by reading line 18 directly. |

All five were re-checked directly against the committed `ch01.txt`: each
string is present exactly once.

## ऋ/ॠ added as a third short/long pair

The plan's original concept text listed `आ ई ऊ ॠ` as the long vowels, and
the first draft of `con.ch01.hrasva-dirgha` dropped ॠ (and ऋ with it),
covering only अ इ उ / आ ई ऊ, because `ॠ` (U+0960) occurs 0 times in chapter
1's extraction (3 times in the whole 16-chapter corpus, all in chapter 5).

Checked against the PDF: ॠ still doesn't appear anywhere in chapter 1. But
ऋ (U+090B, ह्रस्व) does — pages 5, 7, 9, and again in माता का ऋण on page 10.
Since the chapter teaches ऋ, `con.ch01.hrasva-dirgha` now lists it with ॠ
as its long counterpart, so the short/long pair isn't left half-taught. No
exercise pairs them the way `ex.ch01.002`/`ex.ch01.004` do for अ/आ and
उ/ऊ — there's no ॠ word in the chapter to build one from.
